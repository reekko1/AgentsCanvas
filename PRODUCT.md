# Product

## Register

product

## Users

Developers running multiple CLI coding agents (Claude Code today) in parallel — typically 3–10 sessions across different repos. Their context: deep in work, attention is the scarce resource. The job to be done is **supervision**: watching, triaging, and unblocking parallel agent work without becoming the bottleneck. Secondary surface: the same person away from the desk, triaging from a phone via the remote panel.

## Product Purpose

A native macOS infinite-canvas app — "telescope, not a cockpit." Each card is a live agent terminal with a trustworthy status light; the signature move is zooming out to see every agent at once and instantly knowing which one needs you. The app observes and arranges; it never orchestrates. Success = the user trusts the glyphs enough to ignore the canvas until it calls them.

## Brand Personality

Lo-fi dusk studio. Calm, warm, trustworthy. A quiet room of working machines at twilight — not a NASA control room. Three words: **calm, spatial, honest**.

## Anti-references

- **Cockpit/fleet-command dashboards** (dense gauges, broadcast controls, "approve all" buttons) — the product's stated opposite.
- Generic SaaS dashboard chrome: KPI hero metrics, card grids of stats, sidebar-of-everything.
- Alarm-colored UIs where everything pulses; if everything is loud, nothing is.

## Design Principles

1. **Calm by default, loud only when it matters.** Most cards recede; a card earns attention only when it genuinely needs the human. The product lives or dies on this contrast.
2. **Spatial memory is the index.** Location = meaning. Users navigate by where things are; don't bury that under chrome or labels.
3. **Observe, don't orchestrate.** Zoomed out is read-only triage. The user acts by flying in. (Scoped exception: explicit git actions in the Diff Object.)
4. **The status never lies.** A stale or false glyph destroys the product's reason to exist. Honesty beats prettiness in every tradeoff.
5. **Beautiful is part of the product.** Buttery zoom/pan and trustworthy state animation are not polish-for-later; the god-view's credibility depends on them.

## Accessibility & Inclusion

Deferred by explicit decision (pre-launch, no users yet). Keep the existing honest patterns where they're free: status words accompany color beads (never color alone), macOS appearance adaptation already works. Revisit at open-source launch.
