3.4 · Grouping · work concerns

Frames

A frame is a labeled square drawn behind a cluster of cards — a calm boundary that says “these agents belong to one concern.” It’s pure spatial structure: drop the cards for one feature, repo, or workstream inside, name it, and the canvas reads as rooms instead of a wall of windows. Frames stay quiet — a dashed hairline and a small label — so the loud agent glows still own your attention. Click a frame’s label to fly the camera and fit just that group.

A frame’s label carries the concern name, an agent count, and — only when a card inside is loud — a quiet “needs you” tag. The frame itself never glows.

Boundary, not a box

Cards aren’t trapped — a frame is a backdrop you drop them onto. Drag a card out and it simply leaves the group; the frame re-reads its members on the fly.

Click to fit the group

Tapping a frame’s label runs the same camera glide as a card fly-to, framed to that cluster — the fast way to zoom from the whole room into one concern.

Calm by contract

Dashed hairline, faint fill, no halo. Frames give structure without ever competing with the warm glow that means an agent needs you.

3.3 · The Diff Object · the one interactive tool

The diff object

A separate floating tool pointed at a folder’s git working tree. Staged & unstaged groups (a file can sit in both), per-file and bulk actions, a unified diff, and a commit area gated on ≥1 staged change + a message. Try it: select files, stage/unstage on hover, type a message to arm Commit, or discard to trigger the confirmation.
